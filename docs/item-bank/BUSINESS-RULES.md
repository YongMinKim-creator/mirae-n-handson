# legacy/item-bank-php 비즈니스 규칙 후보

> 범위: 문항 검색(`search.php`) · 문항 등록(`register.php`) · 단원 목록(`units.php`)의 조건 · 검증 · 정렬 · 제외 규칙.
> 선행 문서: [ARCHITECTURE.md](ARCHITECTURE.md), [ERD.md](ERD.md).
> 근거 표기는 ERD.md 와 같다. 레거시 코드는 `legacy/item-bank-php/` 를 생략하고(`search.php:215`), 스키마는 `db/mariadb/init/01-schema.sql:70` 처럼 저장소 루트 기준으로 적는다.
> 확신도: **확실** = 조건문 · SQL 로 확인, **추정** = 이름 · 주석 · 언어 동작에서 짐작(실행해 보지 않음).
> 코드에서 확인한 것만 적었다. 이 문서의 어떤 규칙도 실제로 실행해 확인하지는 않았다.

## 0. 먼저 볼 것

- **BR-07: 난이도를 비우면 난이도 5 문항이 빠진다.** 주석은 "1~5 모두 포함"인데 SQL 은 `level < 5` 다. 이관 시 어느 쪽을 따를지 결정이 필요하다(characterization 스냅샷은 레거시 응답 기준이므로 `level < 5` 동작이 기록돼 있을 수 있다).
- **문항 수정 기능은 이 모듈에 없다.** `UPDATE` 문 · 수정 화면이 없다(`grep -n "UPDATE\|DELETE"` 결과는 `register.php:87` 의 `FOR UPDATE` 뿐). 따라서 "수정 시 검증" 규칙은 뽑을 수 없다(§5).
- 검색의 입력 오류는 대부분 **막지 않고 경고만 한 뒤 그대로 조회**한다(BR-05, BR-06, BR-09, BR-11, BR-12, BR-14, BR-15, BR-20). 반면 등록의 입력 오류는 저장을 막는다(BR-28).

## 1. 문항 검색 — 대상 · 조건 조합


### BR-03

### BR-04

### BR-05
- 규칙: 키워드는 앞뒤 공백을 제거하고, 100자를 넘으면 앞 100자만 쓰고 경고한다.

- 비고: 매직 넘버 `100`. 입력창에도 `maxlength="100"`(`search.php:494`)이 있어 두 곳에 같은 값이 따로 있다. 한 글자 키워드는 경고만 하고 그대로 검색한다(`search.php:91-92`).

### BR-06
- 규칙: 단원 코드가 비어 있지 않으면 `unit_code` 가 그 값과 같은 문항만 남기고, 형식이 틀리거나 소문자가 섞이거나 등록되지 않은 코드여도 경고만 하고 그대로 조회한다.
- 근거: `search.php:110-120`, `:141-142`

- 확신도: 확실
- 비고: 형식 = 영문 1자 + 숫자 1~2자 + `-` + 숫자 1~2자. 주석(`:112`)과 경고(`:116`)는 "입력값 그대로 조회"하므로 결과가 대개 0건이라고 하지만, 스키마 collation 이 `utf8mb4_unicode_ci`(`01-schema.sql:18`)라 소문자 `m5-1` 도 `M5-1` 과 일치할 것으로 보인다(**추정**, 실행 확인 안 함). 이 경우 단원명 조회(`:125`)도 성공해 "등록되지 않은 단원" 경고는 뜨지 않는다.

### BR-07
- 규칙: 난이도 값이 비어 있으면 `level < 5` 인 문항만 남긴다(난이도 5 문항 제외).
- 근거: `search.php:213-215`

- 비고: **주석과 코드 불일치.** 주석은 "1~5 모두 포함", 코드는 5 제외. 파일 머리 주석(`search.php:8`)도 "빈값 허용"이라고만 적었다. 난이도 선택 목록의 "전체" 옵션(`search.php:192`)을 고르면 이 분기를 탄다. 매직 넘버 `5`.

### BR-08

### BR-09
- 규칙: 난이도가 비어 있지도 않고 `1`~`5` 한 자리도 아니면 경고한 뒤 정수로 바꾼 값과 같은 문항만 남긴다.
- 근거: `search.php:223-228`
- 근거 코드:

- 확신도: 확실
- 비고: 주석(`:224`)은 "대개 0건". PHP `(int)` 변환 때문에 `abc` → `0`(0건)이지만, `05` · `5.0` · `5abc` 는 `5` 가 되어 경고와 함께 난이도 5 문항이 나올 것으로 보인다(**추정**, 언어 동작 기준). 즉 BR-07 과 달리 이 경로로는 난이도 5 를 조회할 수 있다.

### BR-10
- 규칙: 태그가 비어 있지 않으면 그 이름과 정확히 같은 태그가 붙은 문항만 남긴다.
